# 和议书 Demo｜现场速查

详细操作、所有可复制文本：[完整录制说明](./和议书-Demo录制说明.md)。

本机演示：[打开和议书](http://127.0.0.1:5173/)。先按 README 启动服务。

以下是开录后的操作清单，提交会真实保存到你自己的本地数据库；首次安装不包含作者的历史记录。

## 开录前 2 分钟

- [ ] 网站能访问；录网站窗口，关闭通知，不展示密钥或账户资料。
- [ ] 完整说明在另一窗口，按章节复制文字。
- [ ] 案例选 OpenAir Watch；本轮标记 DEMO-01。
- [ ] 保留旧记录，不说“从空白开始”；本轮只是文字标记，不是独立房间。
- [ ] 左侧角色与即将发言的人一致；每次保存成功再切换。
- [ ] 统一日期：11-01 开始、11-06 演练截止、11-07 首审、11-14 中期、11-28 结束，均为 2026 年。
- [ ] 若需更换日期，先统一改所有文本与表单；履约片段标“虚构教学材料”。

- 修订稿 B 的方案版本：________
- 数据主权方案版本：________
- 紧急状态定义方案版本：________

方案版本、整份文书版本、地图 r 版本是不同概念。老版本不会因本轮录制自动清零。

## 关键转折的四句旁白

1. “五项写满只表示内容完整，不能替任何一方同意。”
2. “附条件接受不能直接算通过，条件要先写进新方案，再请各方重新确认。”
3. “方案通过，不等于整份文书通过。新增的期限、复审和退出安排仍需要分别审阅。”
4. “百分之百是负责人报告完成，只有指定复审人通过后才是已验收。”

## 若卡住，只做这几件事

- 提示新变化：读最新内容，再点表单内“我已核对……”；不要覆盖别人记录。
- 文书无条款：回差异地图确认五项完整、三方对当前版均“接受”。
- AI 超时：先刷新分析记录，不连点付费请求；失败如实说明，继续人工协商。
- 任务无法操作：检查是否是负责人或指定复审人，以及文书是否仍为有效版本。
- 不要在方案确认后修改画像；主线录完再做“原样保存不失效”的可选演示。
- 不把 HTML 导出说成原生 Word/PDF，不把演示角色说成实名签署。
