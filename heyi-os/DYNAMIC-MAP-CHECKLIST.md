# 动态差异地图与 AI 验收

## 案例选择与方案完整性

- [ ] 首页可选择跨国预警合作、校园文化节、社区公共空间改造；进入后角色、画像和议题随案例变化。
- [ ] 各案例的消息、地图关联、方案、确认和 AI 历史互不混入；刷新保留当前案例。
- [ ] 旧医院合作数据保留在 OpenAir Watch 中；切换案例不会清空历史。
- [ ] 在三方已接受方案后原样保存共享画像（包括仅首尾空格变化），版本、历史数量和三方确认均不变。
- [ ] 真实修改共享画像后，关联和受影响方案按原规则等待重新确认。
- [ ] 新方案必须填写谁负责、做什么、何时执行、适用条件、如何复审；缺项不能发布，直接调用接口也会拒绝。
- [ ] 五项填齐只显示形式完整，不会自动获得任何一方的同意；协调员或 AI 不能代替三方批准。
- [ ] 旧版自由文本方案保留原文与历史表态，同时单独标记“旧版内容待补全”；修订为五项方案后需重新确认。
- [ ] 点击“检查方案完整性”只填入提问，用户同意并发送后 AI 才检查当前案例的已共享方案，不上传未发布草稿。

## 地图（不依赖 API 余额）

- [ ] 切换三方角色，在协作画像明确共享立场；地图显示最新文字及版本。
- [ ] 在差异地图点击“关联需求与议题”，建立“需求关联议题”。保存后出现连线。
- [ ] 建立“两项需求存在张力”，选双方需求、议题、理由；地图出现张力节点。
- [ ] 点击节点或连线，查看理由、引用编号和原文。案例初始数据明确标记为示例。
- [ ] 在议题中提交方案，出现议题到方案的连线；再建立“方案回应需求”。
- [ ] 三方分别提交异议、附条件接受或需要信息；地图自动出现相应反馈节点。
- [ ] 修改共享立场或方案，旧关系显示虚线和“待复核”，不覆盖旧依据。
- [ ] 填写原因撤销关联；开启“包含撤销关系”能检查历史关系。
- [ ] 第二窗口约 2 秒内看到地图变化。草稿尚未共享时不会触发地图变化。
- [ ] 三方明确接受同一有效方案才算确认；聊天、AI 回答或地图关联均不代替表态。

## AI（需要 API 账户有可用余额）

- [ ] 地图与会议室均有 AI 面板；“配置密钥”和“成功调用”状态分别展示。
- [ ] 不勾选数据发送同意时不能发送。不会自动上传未提交草稿。
- [ ] 选择“分析差异地图”，发送后出现真实回答、原文引用与待审核建议。
- [ ] 点击“我已核对，加入地图”，才会保存关联，并保留 AI 请求编号。
- [ ] 来源变化后，旧 AI 建议不能直接采纳；需重新分析。
- [ ] 从会议室总结讨论，后续提问可参考最近 3 次成功问答摘要。
- [ ] 失败时显示真实原因，不显示预设答案；历史中保留失败记录。
- [ ] 刷新页面或切换角色可看到共享历史；刷新不调用模型，不产生模型费用。

## 已知边界

当前仍是演示角色切换，不是账号与项目权限绑定；不要输入真实敏感信息。仅有网站平台的访问边界，发布范围维持原 owner-private 设置。AI 建议不是法律、医疗结论，也不是任何一方的同意。

服务端经第三方平台 ACCTOKEN（`https://www.acctoken.com/v1`）调用 `deepseek-v4.1-flash`，使用兼容 Responses 接口及 `store:false`。数据仍需经过 ACCTOKEN 及其上游，不能将该参数视为供应商零留存保证。最多 6 请求/分钟、60 请求/24小时、单次输出上限 4500 tokens；这是应用次数限制，不是账户总费用保证。密钥只在服务器使用，本地 `.env.local` 不提交 Git。

服务端配置使用 `ACCTOKEN_API_KEY`（机密）、`ACCTOKEN_BASE_URL`、`ACCTOKEN_MODEL`。不再使用或回退到旧 OpenAI 配置。切换前打开的旧页面必须刷新并重新确认服务商的数据发送说明；不要把“已配置”误认为“已成功调用”。余额、令牌额度和模型权限应在 ACCTOKEN 控制台检查。

自动测试：`node --experimental-strip-types --test tests/collaboration.test.mjs tests/difference-graph.test.mjs tests/cases-proposals.test.mjs`。本地生产预览使用隔离数据库后运行 `tests/collaboration-api.mjs`、`tests/difference-graph-api.mjs`、`tests/cases-api.mjs`（均使用 Node strip-types；写入验收数据，仅允许 localhost，目标地址通过 `HEYI_TEST_URL` 环境变量指定）。跨案例 AI 采纳测试使用标明为本地测试的历史 AI 固定样本，不调用付费模型。全站案例共用 AI 次数限制。
